## 👨‍💻 Sobre mim

Sou estudante de Ciência da Computação na PUC Minas (3º semestre) e Ciência de Dados na UFMS (EAD), com mais de 3 anos de experiência em programação. Tenho interesse em desenvolvimento full-stack, estruturas de dados, automação e projetos que unem backend robusto com interfaces bem construídas.

Atualmente estou desenvolvendo projetos pessoais que vão de bots para WhatsApp a gerenciadores de snippets de código — sempre buscando aprender na prática.
